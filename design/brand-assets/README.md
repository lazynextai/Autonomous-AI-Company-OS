# Publication wordmarks

Transparent PNG wordmarks, 500 × 125 pixels, for the Lazynext Hashnode
publication. These use the established dark background and purple L mark.

- `wordmark-light.png`: dark text for light backgrounds.
- `wordmark-dark.png`: light text for dark backgrounds.

Uploaded and saved to the existing publication on 2026-10-12. The favicon
uses the existing `dashboard/public/icon-512.png`; the social preview uses
the existing `marketing/public/og.png`.
