<https://api.lazynext.com/openapi.json>. It was generated with Postman's
`openapi-to-postmanv2` converter. `baseUrl` defaults to the API custom domain.

Import `accessibility-checker.collection.json` into Postman to use a local copy.
No credentials are included. Replace generated example values with values for
your intended request. Begin with descriptor, health, OpenAPI and rules GETs.
Do not run the whole collection automatically: scans consume quota; lead,
monitor, unsubscribe, confirmation and cancellation operations change state.
Dodo billing remains in test mode by founder choice.

and paths matching the generated collection, with matching collection variables.
The workspace returned `visibility: personal`; its collection is visible in
the signed-in browser. Postman adds metadata and reorders returned requests,
so byte-for-byte equality is not used as the comparison.
