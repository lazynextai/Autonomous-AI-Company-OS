      What this checks
      
      
      The Lazynext AI Slop Checker merges the ideas behind five open-source anti-slop projects into one deterministic engine:
        no-ai-slop and stop-slop for writing tells, kill-ai-slop for visual and copy tics,
        impeccable for its design vocabulary, and hallmark for its hard design floor.
        Every pattern is a fixed rule with a human fix: no model, no API key, and the same input always gives the same score.
      
      
        
        
      • Text tells: 21 categories of AI-dialect words, filler phrases, binary contrasts, and rhythm crutches.
        • 
        
      • Design tells: 6 categories of machine-default UI: indigo-violet gradients, kickers, glassmorphism, badge spam, invented stat rows and more.
        • 
        
      • Safe rewrites: conservative before/after suggestions for the most fixable patterns.
        • 
        
      • Runs anywhere: this page runs the whole engine in your browser; no server required.
        •
