## 2. What is NOT slop (and why it stays)

The high scores on README / ATTRIBUTIONS / SKILL / CLAUDE are **deliberate
quotations**: those documents must list the words the tool flags (`delve`,
`tapestry`, `game-changer`, …), show CLI examples
(`node api/cli.js "We must leverage this robust cutting-edge solution."`),
and reproduce the JSON report shape — all of which the scanner correctly
scores. Rewriting them would destroy the documentation's purpose. They were
audited line-by-line: every flagged token is inside a quotation, an example,
or a factual list entry, not in our own descriptive prose.

## 3. Real finds — fixed

### Find 1: `web/index.html` — em-dash habit (11 → 1)

Our own checker page used an em dash as a definition-list separator and in
prose — 11 em-dashes in ~140 lines. The scanner's own `e-em-dash` rule
(named for exactly this behaviour) flagged it. Fixed by converting the
definition-list separators to colons (the natural form for
"Label: description") and one prose dash to a colon.

### Find 4 (during development): `web/app.js` — middle-dot chain in the new
project-report summary

The new in-browser project scan put a middle-dot pair into its summary
string (`…with hits · N tell(s) · score…`), which the `d-middle-dots` rule
flags as a meta-string chain. Rewritten to semicolons before commit;
`web/app.js` scores 0/0 in the final bench.

Before (1 of 5):
```html
<li><strong>Text tells</strong> — 22 categories of AI-dialect words, ...</li>
```
After:
```html
<li><strong>Text tells:</strong> 22 categories of AI-dialect words, ...</li>
```

### Find 2: `web/index.html` — middle-dot footer chains

The footer used "·" to join three items on one line — exactly the
`d-middle-dots` pattern ("meta strings joined with middle dots"). Fixed by
keeping at most one dot per line (per the rule's own fix) and switching the
second separator to a pipe.

Before:
```html
<p>© 2026 UNITED GLOBAL VENTURES PRIVATE LIMITED · lazynext.com · support@lazynext.com</p>
<p class="hint">Lazynext AI Slop Checker · MIT licensed · <span id="engine-version"></span></p>
```
After:
```html
<p>© 2026 UNITED GLOBAL VENTURES PRIVATE LIMITED · lazynext.com | support@lazynext.com</p>
<p class="hint">Lazynext AI Slop Checker · MIT licensed <span id="engine-version"></span></p>
```

### Find 3: `skill/references/visual-tells.md` — em-dash cluster + a banned adverb

Two real hits in our own prose inside the field guide (not an example
quote): an em-dash cluster (4 dashes) and the word "genuinely" (an
`a-genuinely` adverb tell) in "Number what is genuinely ordered".

Before:
```markdown
wall of glowing cards — every default switched on at once, until every
...
| `01 / 02 / 03` markers | ... | Number what is genuinely ordered |
- **The tasteful terminal** — mono everywhere, near-black background, one
```
After:
```markdown
wall of glowing cards, every default switched on at once, until every
...
| `01 / 02 / 03` markers | ... | Number only ordered content |
- **The tasteful terminal**: mono everywhere, near-black background, one
```
